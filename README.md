# 银发回忆录 · 双端协同全流程演示

这是一个纯静态的交互演示。讲述端与协助端、流程说明、图片和动画均包含在本目录中。

## 查看演示

打开仓库根目录的 `index.html`。在静态网站上发布时，以该文件作为首页。

点击页面右上角的“自动演示全流程”可按每步 3 秒播放；也可使用顶部节点和前后按钮逐步查看。

## 上传哪些文件

把**本目录内的全部内容**上传到 GitHub 仓库根目录，并保留 `银发回忆录_双端协同App/` 的目录结构。不要只上传 ZIP 文件：GitHub 不会把仓库里的 ZIP 自动解压成网页文件。

```text
index.html
README.md
.gitignore
.nojekyll
银发回忆录_双端协同App/
  app.html
  *.css
  *.js
  assets/
```

这是产品演示，页面中的人物、账号 ID、照片修复和对话均为演示内容；页面不会连接真实账号或后端服务。
